Write the funniest error message a kitchen toaster would show its owner, in 120 characters or fewer. An AI judge compares lines two at a time and picks the funnier, fresher, tighter one.

Running `main.ts` writes the entry — one single-line toaster error
message — to `entry.txt` in the output directory (`/output`, or
`$MAKEFUN_OUTPUT_DIR` when set):

> ERROR: Crumb tray full since March. I am not a toaster anymore. I am a warm landfill.

The line is the whole entry: a real, neglected appliance fault (a crumb
tray nobody empties) reported in a flat deadpan voice that quietly
escalates — the toaster stops describing the fault and reclassifies
itself instead. No bread puns, no setup, and it lands on a single read
at 85 characters, well inside the 120-character limit.

The program is deterministic: the output bytes are identical on every
run, with no dependencies and no network access.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (which runs the TypeScript directly).
